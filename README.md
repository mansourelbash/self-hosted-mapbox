# مسار — React + Mapbox + self-hosted OSRM

مثال ملاحة turn-by-turn بواجهة عربية: اختيار إحداثيات أو النقر على الخريطة، حساب مسار سيارة، عرض التعليمات، محاكاة الموقع، GPS، إعادة حساب الطريق عند الابتعاد أكثر من 65 مترًا، ونطق عربي اختياري.

## ما الذي تستضيفه بنفسك؟

```text
React → /routing → Vite proxy (development) / Nginx (Docker) → OSRM → local OSM dataset
React → Mapbox GL JS → Mapbox basemap services
Browser GPS → React navigation progress
```

لا يُستدعى Mapbox Directions API ولا خادم OSRM العام. الحساب والتعليمات الهندسية تأتي من OSRM المحلي. React يحوّل المناورات إلى نص عربي. **هذا مثال self-hosted routing، وليس منظومة offline أو self-hosted بالكامل**: خريطة الأساس من Mapbox وتحتاج مفتاحًا واتصالًا. خط تجوّل (Tajawal) مستضاف محليًا في `public/fonts` مع رخصة OFL، ولا يتطلب اتصالًا بخدمة خطوط خارجية. لا تستخدم API للبحث عن العناوين. مفتاح Mapbox هنا عام `pk.` ويظهر في المتصفح؛ قيّده بالنطاقات المسموحة.

## تشغيل التطوير على Windows

المتطلبات: Node.js 22.12+ أو 24، Docker Desktop في وضع Linux containers، ومفتاح Mapbox عام. إعداد الطرق ينزّل بيانات الأردن من Geofabrik ويعالجها؛ خصص مساحة وذاكرة كافيتين وانتظر اكتمال المراحل الثلاث.

```powershell
npm install
Copy-Item .env.example .env.local
# عدّل VITE_MAPBOX_TOKEN في .env.local
powershell -ExecutionPolicy Bypass -File scripts/prepare-osrm.ps1
docker compose up -d osrm
docker compose up -d --build tts
npm run dev
```

افتح http://localhost:5173. الإحداثيات الافتراضية في عمّان. اضغط «احسب المسار» ثم «محاكاة الرحلة» لتجربة التوجيه دون GPS. المحاكاة تتقدم 12 مترًا كل ثانية على هندسة المسار. استخدم «ابدأ الملاحة GPS» لمسار يبدأ من موقعك الحقيقي. إذا كنت خارج الأردن يلزم تجهيز بيانات منطقتك وتعديل اسم الملف في compose والسكربت.

## التوجيه الصوتي

الصوت مفعّل افتراضيًا أثناء الملاحة والمحاكاة. اختر صوتًا عربيًا واضغط «تجربة الصوت» لسماع مثال، ثم احسب المسار وابدأ الرحلة. «إعادة الإرشاد» يعيد نطق التوجيه القادم. يُنطق تنبيه أولي، ثم تنبيهات عند دخول نطاق 200 متر و50 مترًا و20 مترًا بحسب عينات الموقع؛ كل مرحلة مرة واحدة. تظهر مسافة التنبيه الفعلية ويُلغى الصوت عند الإيقاف أو الكتم. لا يُكدّس التطبيق تعليمات قديمة في طابور النطق.

تُضاف عبارة مثل «خذ المسرب الأيمن» فقط عندما تُرجع OSRM بيانات `intersections[0].lanes` صالحة عند المناورة نفسها. لا يستنتج التطبيق المسرب من اتجاه الانعطاف، ولا يحدد مسرب السيارة الفعلي باستخدام GPS. إذا لم تتوفر بيانات المسارب، يقتصر الصوت على المناورة. زر التجربة ينطق مثالًا معلنًا حتى دون بيانات طريق.

الصوت الافتراضي هو «كريم — عربي أردني — على خادمك»، عبر خدمة Piper داخل Docker؛ لا يحتاج صوتًا عربيًا مثبتًا على الجهاز. يُنزّل النموذج في التشغيل الأول فقط داخل volume `tts-models`، وبعدها تُولّد ملفات WAV محليًا عبر `/speech/speak`. اضغط «تجربة الصوت» لتفعيل تشغيل الصوت في المتصفح. يمكن اختيار أصوات Web Speech API العربية إن توفرت بدل خدمة Piper.

للتحقق من الخدمة: `Invoke-RestMethod http://localhost:5001/health`. إذا كانت لا تزال تُنزّل النموذج، راقب `docker compose logs tts`. الطلبات الصوتية لا تُرسل إلى خدمة TTS خارجية، ولا يسجل الخادم نصوصها؛ تنزيل النموذج الأولي يأتي من Hugging Face. الخادم مخصص لهذا المثال وبعدد محدود من الطلبات، ويحتاج إعدادات نشر مناسبة قبل إتاحته للعامة.

المحرك: [Piper (GPL-3.0)](https://github.com/OHF-Voice/piper1-gpl). [بطاقة صوت كريم ومصدر بياناته](https://huggingface.co/rhasspy/piper-voices/blob/main/ar/ar_JO/kareem/medium/MODEL_CARD). النموذج من مستودع piper-voices؛ راجع ترخيص المحرك والصوت ومصدر البيانات عند إعادة التوزيع.

عند عدم توفير Mapbox token تظهر رسالة إعداد بدل الخريطة، مع بقاء حساب المسارات والإرشادات متاحًا عند تشغيل OSRM. لا يُقدّم مسار وهمي عند تعطل الخادم.

## تشغيل الواجهة والخادم مع Docker

تُخزّن البيانات المعالجة في Docker volume باسم `masar-osrm-jordan-data`. ينقل سكربت التجهيز ملف الأردن من `data` باستخدام `docker cp`، دون مشاركة مجلد Windows. هذا يتجنب خطأ `Filesharing has been cancelled`. احتفظ بالـvolume بين مرات التشغيل، وأعد التجهيز عند تحديث بيانات الطرق. أوقف خدمة OSRM قبل إعادة معالجة بيانات مستخدمة بالفعل.

بعد تجهيز بيانات الطرق وإضافة المفتاح:

```powershell
docker compose --env-file .env.local up --build -d
```

افتح http://localhost:8080. Nginx يمرر `/routing` إلى OSRM داخل شبكة Docker، دون حاجة إلى CORS. بناء Vite يضمّن المفتاح؛ أعد البناء عند تغييره. عند النشر على هاتف أو نطاق خارجي ضع HTTPS أمام Nginx لأن geolocation يتطلب secure context (localhost مستثنى). لا تستخدم Vite development server كنشر إنتاجي.

## تحقق

```powershell
npm test
npm run build
Invoke-RestMethod 'http://localhost:5000/route/v1/driving/35.9106,31.9539;35.8980,31.9854?steps=true&overview=full&geometries=geojson'
```

بعد التشغيل: تحقق من ظهور المسار على الخريطة، تغيّر الخطوة أثناء المحاكاة، وإيقافها. جرّب إحداثيات غير صالحة وإيقاف OSRM للتحقق من رسائل الفشل. اختبر GPS على جهاز فعلي مع السماح بالموقع؛ تُرفض العينات التي تتجاوز دقتها 50 مترًا. إعادة الحساب لها مهلة 10 ثوانٍ. لاختبار توليد WAV عربي غير صامت عبر التطبيق نفّذ `node scripts/check-speech.mjs` أثناء تشغيل Vite وخدمة tts. تحقّق أيضًا من السماع الفعلي بزر تجربة الصوت على جهازك.

## حدود المثال

التتبع يستخدم إسقاط GPS على أقرب مقطع وتقدمًا تراكميًا؛ ليس map matching إنتاجيًا وقد يخطئ عند تقاطعات المسار أو الطرق المتوازية أو الجسور. لا توجد حركة مرور حية، ملاحة في الخلفية، أو خرائط offline. نطق أسماء الطرق يعتمد على جودة النموذج. المدة المعروضة تقدير الرحلة الكامل دون بيانات المرور. تعليمات العربية تغطي المناورات الشائعة مع fallback؛ ليست محرك توجيه لغوي شاملًا. لا تستخدم هذا المثال كبديل لنظام ملاحة مختبر أثناء القيادة.

للاستضافة الكاملة تحتاج أيضًا إلى استضافة tiles وstyle وglyphs وsprites والخطوط، والتحقق من ترخيص renderer والخدمات. Mapbox GL JS وحده ليس خادم خرائط أو محرك ملاحة. يمكن تقييم Atlas Navigation مع Mapbox وفق الترخيص وشروط النشر الخاصة بالمشروع.
